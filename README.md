🛒 RedStore – eCommerce Website

RedStore is a static eCommerce website built using HTML and CSS. It provides a simple and responsive online shopping interface with multiple pages such as Home, Products, About, Contact, and Account.

This project is suitable for web development assignments, college projects, and frontend practice.

📌 Features

Responsive navigation bar

Home page with featured & latest products

Products listing page

About Us page

Contact Us page

User Account information page

Clean UI with reusable CSS styling

🛠️ Technologies Used

HTML5

CSS3

Font Awesome Icons

Responsive Layout (Flexbox)

📂 Project Structure
RedStore/
│
├── index.html        # Home page
├── Products.html     # Products listing page
├── about.html        # About page
├── contact.html      # Contact page
├── Account.html      # User account page
├── style.css         # Main stylesheet
├── images/           # Images (logo, products, banners, etc.)
└── README.md         # Project documentation

🚀 How to Run the Project

Download or clone the repository:

git clone https://github.com/your-username/redstore.git


Open the project folder

Double-click index.html
or
Open it using Live Server in VS Code
